# Build 42 target; MVP is full systems core plus one complete starter class

The mod targets Build 42 only (B41 unsupported). MVP (“base working”) is: lore/Rising rules, Personal Level and XP, SP into base skills and stats, System Tab, class pick at Personal Level 10, and **at least one fully realized starter class** with its three Class Skills. Remaining classes may stub until after the first class proves the pipeline. Specializations at 25/50 stay out of MVP.
