# SP pending cart persists until Confirm; per-tab carts

Unconfirmed plus/minus SP adjustments persist when switching or closing tabs until the player hits that tab’s Confirm, or until death/logout clears state as implementation requires. Skills tab and System Tab each keep an independent pending cart and their own bottom Confirm button. Inventory/crafting use the same blue System chrome as the character sheet (icons unchanged). UI label for world pressure is World Rank.
