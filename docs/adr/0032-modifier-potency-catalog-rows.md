# Percentage Modifier potency is separate catalog rows (I/II)

To fill higher Modifier Tier slots without illegal duplicate ids, percentage Modifiers use **distinct catalog entries** per potency: e.g. `thick_skin` (Tier 1, base %) and `thick_skin_2` (Tier 2, **double** %). Same pattern for Hardened Skin, Heavy Hit, and System Hardened only—not binary Modifiers, not Evolved. A loadout may include at most one entry from a family. Analyze shows “Thick Skin” / “Thick Skin II”. Rejected: same id stacked; placing one row in multiple tiers; freeform III+ in base package.
