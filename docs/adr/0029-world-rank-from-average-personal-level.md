# World Rank readout follows World Level progression

World Rank remains the System Tab label for how hard the world is. Its value and meaning follow **World Level** (ADR 0031: time leg + average PL leg), not a separate parallel curve. Average Personal Level still matters as an **input** to World Level; activity window still applies to who enters the average. Modifier loadouts and System Tier weights escalate smoothly with that progression. Supersedes the “World Rank = average PL alone” framing where it conflicted with World Level as the driver.
