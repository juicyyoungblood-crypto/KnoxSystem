# Class Skills use 0–10 (cap-aware) levels and 3× regular skill XP

Class Skills follow the same level band as ordinary base skills (typically 0–10, respecting mod-raised caps where applicable). XP required per level is three times the regular (non-passive) base skill XP table — slower than combat/craft skills, still far below Strength/Fitness passives. Class Skills never take SP purchases in the base design; they only advance via their activity XP rules.
