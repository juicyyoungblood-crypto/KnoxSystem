# Zombie Modifiers use their own tier ladder gated by World Level

Spawn stamps System Tier for the baseline stat package. **Sprinter** is a speed flag (not a Modifier), only when **World Level ≥ 5** (Goblin alone may sprint earlier). Elite promote assigns **Elite Rank 1–4** packages (ADR 0033) plus a **Modifier Loadout**. Named specials live in `design/zombie_mutations.yaml`.

**Loadout spine:**
- Low World Level: non-elites 0 Modifiers; elites 1–2× Tier 1.
- High end (WL 40) elites: always exactly 6 = 1× T4 + 1–2× T3 + 1–2× T2 + T1 fill.
- T4 loadout mods elite-only. Non-elites at high WL: 1–3 from T1–T3.
- **Goblin** (Tier 0): independent ~1/500 roll (ADR 0034).

**Hard anti-combos:** Screecher ⟂ Silent; Anchored ⟂ sprinter; Evolved ⟂ Anchored; Relentless ⟂ Anchored.

Rejected: Mutation glossary term; long-memory follow; T4 loadout on common zombies; fixed cumulative tag kit per System Tier.
