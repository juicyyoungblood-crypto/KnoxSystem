# Elite corpses and names use Elite Rank + Zombie

Elite zombies no longer present System Tier names (Marked Zombie, Apex Zombie-as-tier, etc.) on corpse or elite nameplate copy. Display is **Apex Zombie**, **Elite Zombie**, **System Elite Zombie**, or **System Champion Zombie** from Elite Rank. Non-elites keep System Tier + Zombie (e.g. Marked Zombie). Eye glow remains elite-only. Supersedes ADR 0022 corpse tier-only rule for **elites**.
