# Skill Points buy base skill levels or Personal Stats only

On Personal Level-up the survivor gains Skill Points. SP may raise base skills (tiered cost by target level) or Personal Stats (1 SP per stat level, max 20). Class Skills are not SP-purchasable in the base design; they level from their own activity XP. Spending SP on a base skill instantly grants that skill level (same as having leveled it), without converting or refunding base skill XP. Chosen for a clear mental model and UI, accepting that SP economy must be tuned so early skills are not trivialized.
