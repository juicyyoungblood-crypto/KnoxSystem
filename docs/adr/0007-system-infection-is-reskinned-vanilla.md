# While-alive infection is vanilla under the hood, reskinned as System

For the base layer, while-alive zombification keeps vanilla infection behavior and hooks, presented as System Infection. Resilience modifies contraction/progress per the stat design and grants full immunity at 20. Rising on death remains a separate rule (always Rise unless Resilience is max). This preserves familiar bite tension and implementation leverage while lore still treats the System as the cause, not a second pathogen.
