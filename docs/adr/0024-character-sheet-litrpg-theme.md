# System UI theme covers character sheet, inventory, and crafting

Knox System restyles the character-sheet tabs (Info, Skills, Health, Protection, Temperature, System) plus inventory and crafting to a LitRPG System look: blue panels, white primary text, grey-to-white quantitative ramps (Protection 0 dark grey → 100 white). Health may retain a desaturated red–grey wound severity map for readability. Main HUD moodles/hotbar are out of this scope unless decided later. Prefer coherence over leaving vanilla parchment beside System panels.
