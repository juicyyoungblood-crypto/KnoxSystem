# Goblin is Modifier Tier 0 ultra-rare coward

**Goblin** is the only Modifier Tier 0 entry. **Stamp order:** roll Goblin first (~1/500 from World Level 0). On hit: **no** other Modifiers, **no** Modifier Loadout, **no** Elite Rank promote. Behavior: flee survivor; LOS broken for 15s → despawn; neighborhood size picks sprinter (<5 other zeds) vs fast shambler (≥5), ignoring World Level sprinter gate; death always drops two equal-weight rolls from its fixed loot table. Not an Elite Rank.
