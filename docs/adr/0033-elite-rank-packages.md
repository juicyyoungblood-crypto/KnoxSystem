# Elite promote uses Elite Rank 1–4 packages

When a zombie is promoted off the common pool, it receives an **Elite Rank** with a fixed package—not only a generic +HP elite:

1. **Apex** (Elite Rank 1): +25% HP, +25% detection chance  
2. **Elite** (Elite Rank 2): +50% HP, +30% detection range, −20% damage taken  
3. **System Elite** (Elite Rank 3): +100% HP, +30% detection range, −30% damage taken, −50% chance to be knocked down  
4. **System Champion** (Elite Rank 4): +150% HP, +30% detection range, −50% damage taken, knockdown immune, screech on death  

Rank weights rise with World Level (higher ranks rarer early). Eye glow remains elite-only. **Elite Rank name “Apex” ≠ System Tier name Apex.** Modifier Loadouts still layer on top per ADR 0028. Old flat `elite_extra` mult-only package is superseded for design SoT.
