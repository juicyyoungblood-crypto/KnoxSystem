# Knox System

Project Zomboid Build 42 LitRPG / System layer (private share link).

## Version

**0.6.22** (PLATE_REV 23)

## Install

Copy the `42/` (and `common/` if present) tree into:

`Zomboid/mods/KnoxSystem/`

Or use `mod/Contents/mods/KnoxSystem/` from this repo.

Enable on the **save** mods list, not only the main menu.
